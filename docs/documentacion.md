# Documentación de HogarService
## 1. Modelo del sistema

HogarService está formado por usuarios, profesionales, servicios, categorías, provincias, ciudades, disponibilidades, solicitudes, valoraciones y favoritos.

El sistema permite que los profesionales publiquen servicios y que los usuarios puedan buscarlos, contratarlos y valorarlos.

## 2. Organización del trabajo

Para desarrollar HogarService nos organizamos distribuyendo las funcionalidades entre los tres integrantes del grupo.

Comenzamos por los CRUD y luego avanzamos con las relaciones entre entidades, los listados y las funcionalidades principales de la aplicación.

Cada integrante fue realizando sus aportes al frontend y al backend, integrando los cambios en el repositorio compartido.

Utilizamos Git y GitHub para gestionar el código y registrar los avances mediante commits.

## 3. Seguimiento del desarrollo

El seguimiento del proyecto se realizó principalmente a través de los cambios registrados en GitHub.

Las funcionalidades desarrolladas incluyen la gestión de usuarios, profesionales, categorías, provincias, ciudades, servicios, disponibilidades, solicitudes, favoritos y valoraciones.

También se implementaron los listados de servicios con filtros y sus respectivos detalles.

El inicio de sesión con roles y los tests automatizados se encuentran pendientes.
